# YUHANA - Sistem Inventori

Sistem Inventori Barang adalah aplikasi web yang dibuat sebagai project pembelajaran React untuk memahami cara membangun aplikasi berbasis data menggunakan React.

Aplikasi ini mensimulasikan sistem inventori dengan 3 role pengguna, yaitu Admin, Petugas, dan Peminjam, yang memiliki halaman dan fitur berbeda sesuai dengan perannya.

## Role Pengguna

### Admin

* Melihat dashboard
* Mengelola data barang
* Mengelola data pengguna
* Melihat dan mengelola data peminjaman

### Petugas

* Melihat data barang
* Memproses peminjaman
* Memproses pengembalian
* Memantau status peminjaman

### Peminjam

* Melihat daftar barang
* Mencari dan memfilter barang
* Mengajukan peminjaman
* Melihat status peminjaman

## Catatan

Project ini hanya dibuat untuk pembelajaran React dan belum menggunakan backend maupun database. Data akan disimpan menggunakan state React dan/atau localStorage sehingga sistem belum memiliki authentication, authorization, dan keamanan seperti aplikasi production.
